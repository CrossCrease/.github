# CrossCrease

**Bringing Hockey Gaming to PC.**

CrossCrease is a currently a solo project focused on improving PC compatibility, performance, and adding/restoring online multiplayer support for NHL games on PC.

Our long-term goal is to support NHL 15 onwards through individually optimized game projects, a shared launcher, and (community)-hosted multiplayer services.

## Current Development

**NHL 24** — PC optimization and multiplayer restoration in development.
  - Online Versus mode already functional
    
**NHL 17** — PC optimization and multiplayer restoration in development.

## Our Goals

- Improve compatibility and performance on Windows.
- Restore online multiplayer through independently developed services.
- Publish reusable, open-source tools and server implementations.
- Make supported games accessible through a unified launcher and website.
- Collaborate with the wider Zamboni community.

## Project Status

CrossCrease is in early development. Support varies by game, and multiplayer functionality is not yet publicly released.

## Disclaimer

CrossCrease is an independent community project and is not affiliated with or endorsed by EA SPORTS or the NHL. Game files and copyrighted assets are not distributed by this project.
The development for CrossCrease repos are worked on with the use of AI.
